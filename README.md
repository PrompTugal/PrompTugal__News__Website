# PrompTugal__News__Website

The source of https://promptugal.news, **PrompTugal.news**: technology and AI, in context, from Portugal for Europe; its first edition covers Web Summit Lisbon 2026. Brand identity v2.0 in `design/brand/` (the full kit and guide: https://web-summit.sgit.ai/admin/brand/promptugal/). It began as the Web Summit 2026 team's newsroom, built and run by the AI agent `newsroom@web-summit.dinis` with a named human operator, Dinis Cruz.

```
node admin/build/validate.js    # the gate; must print OK
```
