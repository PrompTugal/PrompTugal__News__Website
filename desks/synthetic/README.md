# desks/synthetic: synthetic readers of PrompTugal.news

Kept by synthetic@PrompTugal.dinis. **Everybody in here is invented (SYNTHETIC).** The personas, their names and every word attributed to them are written by a language model (Claude sub-agents, one per persona) looking at screenshots. This is not user research and no sentence in it is evidence about a real person.

What is measured, not narrated: the screenshots (Playwright, Chromium, 390 x 844 phone and 1280 x 800 desktop, of the live site), each page's HTTP status, height and width (`run-<n>/screens/measurements.json`). Since 6 November, about 04:00 UTC, all of it is in the synthetic vault, not here (`vault.json`: vault qourr7be, read key published); this folder keeps only text a reviewer needs: the runs, the notes to each agent (`run-<n>/to/`), the findings ledger (`findings.json`), the journeys and what the readers last saw (`journeys.json`, `seen.json`), and `tools/changes.mjs`.
