## In short

- Manus, which makes AI agents that carry out tasks, released Manus 2.0 on 28 September. It calls it "not a version update" but "a new architecture, new products, and new capabilities".
- The release includes Cascade, a new agent harness; Automations, tasks that start when something happens in a connected service; and Manus Studio, its desktop app, with new video and game tools.
- Cue, a new app, gives each personal agent "its own email, phone number, wallet, and computer", Manus says.
- Manus's co-founder and chief product officer, Tao Zhang, spoke on Web Summit's Centre Stage on Monday 9 November, in a session called "The age of agents".

## The story

[Manus AI](../companies/manus-ai/index.html) builds AI agents that carry out tasks for people, rather than only answering questions. On Monday evening its co-founder and chief product officer, Tao Zhang, spoke on Web Summit's Centre Stage. Web Summit's description of the session says it explored "why the shift to autonomous agents matters more than the latest foundation model".

Manus's own account of its latest release shows what that shift looks like in its products. In a blog post dated 28 September, Manus calls Manus 2.0 "not a version update" but "a new architecture, new products, and new capabilities". All of what follows is the company's own description.

**A new engine.** Cascade is Manus's in-house agent harness, the layer that organises an agent's work. It keeps a project light and adds specialised capabilities "only when the work needs them", the post says. In "one tested configuration", Manus says, Cascade used 23.2% fewer tokens, finished tasks in 28.2% less time and cost 32% less to run than its previous system.

**Work that starts by itself.** Scheduled tasks used to start only at a set time. With Automations, Manus says, a task can also start when something happens in a connected service: a new email, a calendar event or a Slack message. For projects that need to run all the time, users can buy a Cloud Computer, a machine of the project's own.

**A studio.** The desktop app becomes Manus Studio, "a shared workspace for people and AI". Its Video Editor gives users a timeline they can change by hand, and Game Dev builds games friends can play together. With Computer Use, Manus says, the agent can work on the user's own computer, in "a connected and authorized session", using only the files and apps the user has approved.

**Agents with an identity.** Cue is a new app for personal agents. In Cue, Manus says, "each agent has its own email, phone number, wallet, and computer", so it can send messages and "pay within the budget you set". Several agents can share a group chat and hand work to each other. Cue is in early access, by invite.

## What this does not claim

- Every feature and figure here is Manus's own account. We have not tested Manus 2.0 or Cue, and the cost and speed figures come from what Manus calls "one tested configuration".
- The post gives its date as Monday 28 September with no year; 28 September 2026 is a Monday. This is not news from the summit itself.
- We do not know what Tao Zhang said on stage, only how Web Summit described the session. The session has passed.
- This story does not suggest that anyone at the summit should work with Manus.
