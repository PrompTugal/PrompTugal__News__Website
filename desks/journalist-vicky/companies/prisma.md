## About

Prisma makes tools for building TypeScript apps: Prisma ORM, a way for code to work with a database; Prisma Postgres, a managed database; and Prisma Compute, which hosts the apps (1). It presents them as one stack that a developer's AI coding agent can use to build and deploy an app (1).
