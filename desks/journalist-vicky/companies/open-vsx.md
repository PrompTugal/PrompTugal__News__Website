## About

Open VSX is an open-source registry for VS Code extensions, a project of the Eclipse Foundation (1). The Eclipse Foundation hosts a public registry, and organisations can also run their own, for example inside a company network (1). Its Web Summit page presents Open VSX Managed Registry, a platform for companies to govern, secure and distribute developer extensions and AI artifacts (2).
