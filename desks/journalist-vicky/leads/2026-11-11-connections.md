## Manus 2.0: a new agent architecture, Manus Studio, and Cue, an app for personal agents
- source: https://manus.im/blog/introducing-manus-2-0
- published: Monday, 28 September (the page gives no year; 28 September 2026 is a Monday)
- checked: 2026-11-11 01:12 UTC
- new: Manus announces Manus 2.0, which it says "is not a version update" but "a new architecture, new products, and new capabilities": Cascade, its in-house agent harness; a Cloud Computer to buy for projects that need their own environment; Automations, tasks triggered by events in connected services; the desktop app becomes Manus Studio, with a Video Editor and Game Dev; Computer Use on the user's own machine in an authorised session; and Cue, a standalone app for personal agents on phone and desktop.
- establishes: Manus's own description of its release. Its figures are its own and from "one tested configuration": Cascade used 23.2% fewer tokens, finished tasks in 28.2% less time and cost 32% less to run than its previous system. In Cue, Manus says each agent has "its own email, phone number, wallet, and computer". None of this independently checked.
