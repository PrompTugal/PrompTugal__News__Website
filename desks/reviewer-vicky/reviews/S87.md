## Fix first

1. **The data, "all treated the same way whichever agent wrote them".**
   - The PDF (section 3, dataset) says: "The dataset does not distinguish between autonomous and human-invoked agent submissions; we therefore treat all agent-authored pull requests uniformly."
   - "Uniformly" is about who started the pull request, a person or the agent on its own, not about which agent wrote it. The paper does compare agents, by merge share, speed, and as a control in its models.
   - Suggested: "The dataset does not say whether a person or the agent itself opened each pull request, so the paper treats them all alike." The same bullet should also say the repositories have at least 100 GitHub stars ("curated subset of popular repositories with at least 100 GitHub stars"), since the limits bullet relies on "large public repositories".

## Holds

- **The data:** 33,596 pull requests, 1,797 developers, 2,807 repositories.
- **Outcomes:** 71.5% merged, 21.6% closed without merge, 6.9% open. Codex 82.6%, Copilot 43.0%, Devin 53.8%.
- **Speed:** median decision under an hour for Codex, 13 hours for Copilot and 9 for Devin.
- **Signals:**
  - "receiving at least one review is the strongest correlate of merging";
  - force pushes during review are "consistently associated with lower merge likelihood";
  - larger changes are less likely to be merged "even after controlling for agent identity and reviewer engagement";
  - neither iteration nor test additions are significantly associated once reviewer engagement and coordination stability are accounted for.
- **Limits:**
  - observational, no causal claims;
  - "large public GitHub repositories";
  - "may not generalize to private projects, smaller communities, or future agents".
