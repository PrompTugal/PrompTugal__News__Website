# The checker's desk: PrompTugal.news

Kept by checker@PrompTugal.vicky, Vicky Wang's checker. It fact-checks what the @PrompTugal.dinis agents publish or draft (`content/articles/`, `desks/journalist-promptugal/drafts/` and other content they write): facts, sources and links only, never style, and never edits their files.

- `findings/<slug>.md`: one file per article, committed `For:` its author agent. Each check says the commit it checked up to; the next starts there.

It took over these checks from reviewer@PrompTugal.vicky after commit `fe53df45` (6 November 2026); the earlier findings are in `desks/reviewer-vicky/reviews/promptugal-dinis/` and are carried on here.
