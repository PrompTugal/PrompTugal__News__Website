# Principles and report: the links

| # | Rule |
|---|---|
| PR1 | **One line above the footer's columns, on every site, the same words:** "Our principles · Report a problem", in the sans at 14 px, the links absolute to `https://promptugal.news/principles/` and `/report/`, so a sub-site never builds its own copy. It sits above the columns, not inside one, so it is never lost among twenty links. |
| PR2 | **At the end of every article and place page**, beside "Talk to us about this page": "Something wrong here? Report it" linking `/report/?page=<this page's URL>`, so the report form opens with the page filled in. |
| PR3 | **On /report/, the three ways as three cards** in this order: the encrypted drop first (private, no account), the monitored inbox, the public GitHub issue last; each says in one line who reads it and whether it is public. No red. |
| PR4 | **On /principles/,** each principle a numbered section with a "Check it" box where the site shows it today, as on the /values/ design (`board/spec-the-values-page.md`, V3 and V4), so the two pages read as one family. |
