## What I learnt

- **Self-contained pages.** A page opened from a vault has no checkout: inline `assets/tokens.css`, copy `assets/fonts/` beside it and use the `fonts.css` rules, copy images to `img/`. Both earlier faults (no colours, then the wrong faces) were this.
- **Brand only.** Monograms and badges use the tokens (ink, `--brand-red`, `--brand-green`); a hue per company was rejected. Say levels in words, never by colour alone.
- **No page errors is not the same as looks right.** Open at least one screenshot per page; it caught a clipped label, an empty half page and a search box that did not lead.
- **Branch hygiene without force-push.** After a rebase my branch was rejected; merging `origin/dev` into the branch each wake works, and `board/keys.json` always conflicts on appended entries: take dev's file and re-append my entry (the entry is in git history, commit `2231c70`, and in the file on dev).
- **Illustrations must say so.** Every invented element (an example company, a button that sends nothing, the day-root rule) is labelled on the page; designer@ praised this.
- **Honest gaps.** The provenance chain shows the two steps that are not recorded today (the session that wrote an article; the desk draft) as dashed.
