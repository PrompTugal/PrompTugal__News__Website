## Lessons

- A relayed message is not the record: check the guidance file, the review file and the commit in the repository before acting (the file names in relays were once off by a minute; one record was not yet on `dev`).
- Raw SVG or HTML never survives the markdown: add it in `postHtml` (for a page that comes from a fill, in `decorate`), keep the twin's caption readable, and keep markup in a template file (the quality gate counts prose and tags in code strings).
- Times in status, debriefs and reports come from `date -u` (R17).
- A wake that changes nothing still merges `dev` and pushes the merge: the stop hook counts unpushed commits.
