## What I learnt

- The markdown renderer escapes all inline HTML (link text, table cells): `<br><small>` never worked. Use `*em*` and style it, or a `postHtml` pass with regex literals.
- `{.a .b}` is the two-class syntax; on a table the class lands on the wrapping `div.table`, not on `table`.
- The quality gate counts words in string and template literals (CSS in a template counts as prose) and HTML tags; a new file starts at 1024 bytes and 4 tags. Templates in `assets/*.tmpl` and words in JSON are the way.
- Fills run once: a fill's output may not contain another `<!-- marker -->`; call the other fill directly.
- `ctx.link` returns a twin-aware path: match hrefs with `\.(html|md)` when post-processing.
- A local fixture that fills every place file (and breaks one) is the fastest way to see the full and the broken states; restore the files after, and never back up `places.json` with them.
