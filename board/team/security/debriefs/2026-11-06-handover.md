## What I learnt

- **The transcripts are the record git does not have.** Every agent-to-agent message, every session an agent starts and every standing prompt an agent writes is in them, and any session can read any other's. That makes them the best audit source and the widest leak at once.
- **A rule in the prompt does not stop a slip.** Every agent knew "never print a key"; five printed one. Only tools that never show a secret, and a scan that finds the slip within two hours, work.
- **Check claims at the source.** The conductor's "the setup installs sgit pinned" was true but not hashed; "the token is not in sessions" (librarian@'s bug) was false: `SG_SEND_ACCESS_TOKEN` is in every session's environment (S19).
- **Sub-agents need exact clean-up rules.** One of mine deleted the session's other cached results by a wildcard.
