## What holds
- **No network and no code from data.** No fetch, XHR, dynamic import, eval, `Function`, storage, cookie or postMessage.
- **Elements:** built with `createElementNS` and `setAttribute`, with attribute names written in the code. Every label is written with `textContent` and cut to a length. No innerHTML.
- **Links:** kept only if `new URL` gives https, no user info, no port, and a host of `promptugal.news` or `*.promptugal.news`. Anything else drops the link and keeps the dot.
- **Numbers:** coordinates must be finite numbers, counts are clamped to 0 to 999, and at most 400 places are drawn.
- **The CSS** has no `url()` or `@import`.

## Low, for designer@ (not blockers; fix in 1.0.1)
1. **`el()` walks attributes with `for (var k in a)`,** which also visits inherited keys. If a host page ever had `Object.prototype` polluted, an `onclick` could be added to every map element. Use `Object.keys(a)`.
2. **Licence notice (for rights@):** the outline comes through world-atlas (ISC). Natural Earth is public domain, but ISC asks for its notice with copies. Carry the world-atlas notice in `manifest.json` and the vendored folder, or rebuild the outline straight from Natural Earth.
