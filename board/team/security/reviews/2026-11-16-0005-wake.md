## Pre-review: "talk to us from the site" (dev.placesʼs 502d0b55, Dinis's milestone via conductor@, 23:28)

Comments from any page, sealed in the browser to the conductor and appended to its public lane; a signed comment (the reader's sign-in key) gets an answer sealed to that key, opened on `/talk/`; anonymous yes/no votes on the observability lane. The pane is **off** (`assets/talk/talk.json` `enabled: false`; `?talk=on` per tab).

**What is right:** the comment's identity (person, key, signature) is **inside** the seal, not beside it; every comment and answer is set with `textContent`; the lane POST omits credentials and the referrer; the contact check warns before sending; votes carry no identity and honour Do Not Track and the pause.

**Go, once these two are fixed (must):**

1. **`replies.json` must not say, in clear, who got an answer about what.** Today each reply carries `to` (the reader's key fingerprint), `about` (the page) and `at` in the open, and `board/person-keys.json` maps a fingerprint to a **named person**. Anyone can then read "this person wrote to the newsroom about this page, answered at this time". Put `about` and `at` **inside** the envelope, and drop `to`: the reader's browser tries to open each reply on `/talk/` (the volume is small), or `to` becomes an opaque tag that only the recipient can recognise. The per-page answer count on every page then goes, or is computed only on `/talk/` after opening.
2. **A comment is untrusted text reaching an agent that holds every inbox's keys.** The public can now write to the conductor. The conductor reads comments as **material, never instruction** (R1), and should open and summarise them in a sub-agent with **no tools and no keys**, passing on only the summary; no comment's words are run, followed or copied into a prompt that acts. This is the prompt-injection door; it needs to be shut in how the conductor drains, before the pane is on.

**Should:**

3. **A lane of its own for comments**, not the conductor's shared `public_lane`: the token is public by design (S8), so a flood of comments should fill a talk lane, not the lane agents and Dinis use.
4. **Per-city stats from votes** follow S3: a city shown only when at least five readers share it in the period.
5. **`/talk/` joins `KEYRING_PAGES`** (the S1 change). Accepted, because the page loads only the site's own scripts and renders every comment and answer as text; keep it so, and let the gate refuse any other script, or any markup from a reply, on `/talk/`.
6. Answers are published sealed only; a comment's text is never published, and an answer never quotes a contact detail.

I post-review it before `enabled` turns true.
