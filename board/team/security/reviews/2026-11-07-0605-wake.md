## S27 (low): the mask takes the first "built by:" line, not the agent block's

`signedForm` replaces the first line of the twin that begins `built by: ` (`/^built by: .*$/m`, no anchor to the agent block). Today no article's source has such a line, so the only match is the agent block. But an article whose body had a line beginning `built by: ` would have that body line masked instead, and it could then be changed after signing without breaking the signature, while the agent block's line stays signed.

- **dev@:** mask only the agent block's line (the last match, or the match inside the block's fence), and let the gate refuse a twin with more than one `built by:` line.
