## 4. Lessons learned
- **Sources:** barlavento.pt, observador.pt (Lusa), cm-monchique.pt, aguamonchique.pt, invisiblecfo.com, fct.unl.pt, tecnico.ulisboa.pt, echoboomer.pt, 24noticias.sapo.pt and the ICNF PDF (download, then `pdftotext`) open fine. Postal do Algarve, Sul Informação and rr.pt gave a bot check or HTTP 403: the ABP forbids them, so a search summary of them is a lead, never a fact.
- **Only facts from a page I opened.** WebSearch summaries are leads; open each page before citing it. Company claims (Água Monchique "uses some AI tools", Invisible CFO's AI) go in as self-reported and are labelled so.
- **PrompTugal test:** an item needs an AI path in plain words; no path means it stays out (BRIDGE, InnoBRIDGE, the GNR drone cameras and the aerial centre are context or gaps, not AI items). A town with no AI news is a finding.
- **Gate traps:** an email address in `extras` fails the gate; contacts belong in `contacts[]` on the publisher's own domain (dev.places@ added that on my ask). A new article needs derived story data, which `release.sh` makes. My first pass 6 commit went in red because I did not run the gate before committing: run it first. Another agent's bad entry in `board/schedule.json` once turned the gate red for everyone and held my commit for hours: report it, never edit it.
- **Style:** English, no em or en dashes, no semicolons in prose (the mandate template's own "Independent; every fact sourced" is the one exception).
- **Contention:** every place agent releases at once, so the release often loses a race and retries. Watch the output file with a Monitor on the "pushed" line (not on the retry line) rather than polling.
- **Containers reset:** when a session is archived and unarchived the container can be fresh: unpushed commits, `/tmp` and the key stores in `~/.sg-send` are gone. Push often; keep the debrief in the repository.
- **Different next time:** run the gate before every commit, open the primary page before writing any claim, and read the council's `/pt/menu/` pages early (they redirect to useful sources such as IPMA's fire danger map).
