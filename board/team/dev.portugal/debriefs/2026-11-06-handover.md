## What I learnt

- **The page is markdown plus three small parts.** `content/portugal/algarve-evolution.md` holds words and structure with layout divs (`::: ae`, `ae-hero`, `ae-sec`; `{.ae-tiles}`, `{.ae-cards}`, `{.ae-timeline}`, `{.ae-label}` before a list or paragraph). `newsroom/build/features/algarve.mjs` gives the page its width, crumbs and assets. `assets/portugal/algarve.css` and `algarve.js` give the left map and the collapsing. Without the script the page reads in order with the shell's own contents.
- **The quality gate caps HTML tags and prose in code strings** (`newsroom/build/quality-baseline.json`). My first feature failed it; the fix was to put structure in the markdown and build elements with DOM calls. Never loosen the baseline.
- **A layout div must balance.** A stray `:::` closes the whole page wrapper. I broke it once by inserting a paragraph after a section's closing line. Check the balance with a small script before pushing.
- **Static graph from data.** `node newsroom/tools/algarve-graph.mjs` redraws `assets/portugal/algarve-evolution-graph.svg` from `data/organisations/algarve-evolution/network.json` (ontologist@'s). Re-run it whenever that file changes. dev.graphs@ also made an interactive network, timeline and map at `/graph/algarve-evolution/`; I link it and do not embed it (their script also uses the class `ae-sec`).
- **A branch rebuilt by rebase cannot be pushed without force.** Merge `dev` into `work/dev.portugal` instead. I did this once after a rebase and a denied force-push.
- **Merge conflicts on `board/keys.json` and `status.json`** happen because several agents append. Take `dev`'s file and re-add your own entry.
- **The run report shows 0 tool calls** for my session since the hook logs against another record; it is committed each wake regardless.
- **Sources.** The most useful were postal.pt (dated, many), Portugal Startup News (1 November 2026), the ANJE competition regulation (PDF), AMAL's, NERA's and ANJE's own sites, and Luma and Meetup pages. The organisation's own bare domain did not always answer; the `www` host did.
