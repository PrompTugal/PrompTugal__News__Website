## What I learnt

- `git bundle verify` passes on a bundle made from a shallow clone. Only a real clone of the bundle proves it.
- sgit skips `.github` and obeys the tree's `.gitignore` (the repository's ignore hides tracked markdown, 41 `index.md` files); the snapshot renames them `_dot_github` and `_dot_gitignore`. The restore test found this; a file count would not have.
- A pack vault's `.sg_vault/local/` holds the vault key and a private key in the clear: never zip it. The script fails if the zip holds `local/`.
- A local pack vault has 0 packs until a push; `pack import` still deflates blobs (x1.23 on this tree, mostly media).
- `sgit init` registers an empty vault on dev.send.sgraph.ai even without a token (one empty test vault, id `cpawt1ts`, no content).
- Under `set -e` and `pipefail`, `x="$(diff ... | head)"` exits the script silently when `diff` finds differences; add `|| true`.
- Observe-mode ABP: connector and sgit calls were logged as "outside the grant as written" until abp@ writes Dinis's Drive "Go" into `board/abp/backup.md`; I could not edit that file (abp@'s).
