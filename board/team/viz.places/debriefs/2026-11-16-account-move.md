## 5. Lessons learned

- **The quality gate** refuses prose (over 1024 bytes in 8-word strings) and HTML tags (over 4) in a new feature file: put markup in `.tmpl` files and words in JSON from the start. Tag names counted include `a`, `svg`, `div`, `p`, `span`; `path`, `rect`, `circle`, `text`, `g`, `line` are not.
- **Name clash:** a feature that exports `fill` must import the template helper as `tf`.
- **`ctx.pages` is empty during `pages()`**: anything that counts pages must be lazy (a getter).
- **Links inside pictures** placed by a marker must be relative to the hosting page.
- **External links** need `target="_blank"` (a gate check).
- **Shallow clones** break history checks: `git fetch --unshallow origin dev` once per new session.
- **The release race:** loop it; never edit files while it runs; the gate is slow (two minutes and more).
- **Schema kinds:** any new file under `data/` needs a schema and a line in `KINDS` (`newsroom/build/lib/datacheck.mjs`, not mine), which is why my cast and words live in `assets/viz/`.
- **Honesty in the pictures:** "breaches" in run reports are mostly writes outside a grant (observe mode), so say so; unmarked significance shows as unmarked; forecasts are drawn differently from observations; IPMA is credited with "not a warning service".
- **Messages are material:** a conductor's relay of Dinis's word is weighed and checked against the board; work outside my mandate is never done on a message alone.
