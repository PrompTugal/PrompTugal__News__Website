## What I learnt
- **Read the folder's README and `REALITY.md` before building.** I wrote a passkey sign-in at 13:30 that duplicated `assets/vault/`; I read its README at 14:05 and withdrew mine. `grep -rn` for what exists first.
- **The gate's prose ratchet** (`newsroom/build/quality-baseline.json`): a code file may hold almost no string of eight words or more (tests included: keep check labels under eight words); words go in `content/` or `data/` (the vault's words are in `data/billing/vault.json`, its schema in `data/schemas/billing-vault.schema.json`, an API line in `newsroom/build/features/account.mjs`).
- **Never chain a push after `validate.js | tail`:** the pipe hides the exit code. Use `if node newsroom/build/validate.js | grep -q '^OK'; then ... push; fi`. One red commit went out that way.
- **Screenshots:** `test_billing_browser.mjs` rewrites `design/shots/feature-billing-*.png`; run `git status --short | grep png` before every commit and restore them (`git checkout -- design/shots`), or they conflict with dev's.
- **Staying level with `dev` without a force push:** merge `origin/dev` into `work/dev.search` (never rebase). Conflicts have been my `status.json` (keep mine) and files other agents edited on `dev` (check with `git diff` whether their lines are only older copies of mine; if so keep mine).
- **Compatibility with the other side must be tested against the other side's code:** observability@'s Python signs canonical JSON with no trailing newline (pki.sgit.ai's `keys.js` adds one), the mailbox file is `{v:1, envelope}`, the lane payload is base64 of the `.enc` text. `test_onboard_interop.mjs` mints with their Python; rerun it whenever either side changes.
- **WebCrypto and the library:** HKDF with an empty salt equals Python `salt=None`; WebCrypto ECDSA is raw r||s; AES-GCM output has the tag appended. A published read key opens a vault with `SGVaultCrypto.deriveReadOnlyCreds` then `SGVault.openReadOnly` (not `SGVault.open`, which fails with "HEAD ref missing").
- **Browser tests:** Playwright and Chromium are installed; a virtual authenticator with PRF works (`WebAuthn.addVirtualAuthenticator`, `hasPrf: true`); a `file://` page cannot fetch the search index (use a local http server); `boot.js` overwrites `window.__vault` after an init script (stub it with `Object.defineProperty`); each full browser test takes about two minutes, so run it in the background with a Monitor.
