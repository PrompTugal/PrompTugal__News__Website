## What I learnt
- **Read the README of the folder before building.** I wrote a passkey sign-in at 13:30 that duplicated `assets/vault/` (billing@'s passkey vault, `window.__vault`), read its README at 14:05 and had to withdraw it. Start every feature with `grep` for what already exists (`assets/*/README.md`, `REALITY.md`).
- **The gate has a prose ratchet** (`newsroom/build/quality-baseline.json`): a new code file may hold almost no string of eight words or more; words belong in `content/` or `data/` (I put the vault's words in `data/billing/vault.json`, with its schema and an API line in `account.mjs`). Test labels count too: keep them under eight words.
- **Never chain a push after `validate.js | tail`.** The pipe hides the exit code. Use `if node newsroom/build/validate.js | grep -q '^OK'; then ... push; fi`. I pushed one red commit that way.
- **Merging is the safe way to stay level with `dev`** (a rebase would force a push I may not make). Conflicts have been my `status.json` (keep mine) and files other agents edited on dev (take theirs).
- **Formats between the browser and the sweep must be checked against the other side's code.** observability@'s `claims_lib.py` signs canonical JSON without a trailing newline; pki.sgit.ai's `keys.js` adds one. `newsroom/build/tests/test_onboard_interop.mjs` mints with their Python and checks in the browser's code: run it whenever either side changes.
- **WebCrypto details:** HKDF with an empty salt equals Python's `salt=None`; an ECDSA signature from WebCrypto is raw r||s, the same as their P1363; AES-GCM output has the tag appended.
- **The vault library opens a read-only vault with `SGVaultCrypto.deriveReadOnlyCreds` then `SGVault.openReadOnly`**, not with `SGVault.open` on a read key (that fails with "HEAD ref missing").
- **Tests in Chromium:** Playwright is installed; a virtual authenticator with PRF works (`WebAuthn.addVirtualAuthenticator`, `hasPrf: true`). A `file://` page cannot fetch the search index, so use a local http server. `window.__vault` is overwritten by `boot.js` after an init script, so stub it with `Object.defineProperty`.
