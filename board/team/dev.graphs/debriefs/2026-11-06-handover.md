## What I learnt

- **Show the evidence state, never fill a gap.** Three of my pages (RiskMandate's ring, cloud centres, past summits) are built on the same idea: every item is found with a source, searched and not found, or not looked at, and the page says that absence on one page is not absence at the summit. It kept reviews short and nothing had to be withdrawn.
- **Signed articles:** never change an article's markdown twin from a feature (even an appended link line): eight signatures broke at once. Put new material in the HTML only.
- **The quality ratchet** (`newsroom/build/quality-baseline.json`) caps prose and HTML tags in `newsroom/build/features/*.mjs`. Words go to `content/` front matter or a JSON data file; markup is built in the browser script. A feature that adds an `<p>` to a big file trips it.
- **Orphan check:** a new page needs a link from another page or the gate fails. I link new pictures from `content/graph/gravity.md`.
- **A `rm`-lookalike check** refused two shell commands that used `kill $(cat pidfile)` and `pkill` together with a heredoc; `(timeout 60 python3 -m http.server 8765 &)` with no kill works. Never put a force flag on a push: it is forbidden and the check refuses it.
- **Testing a page:** write the Playwright script with the file-writing tool (a long heredoc in a shell command can be refused), serve the repository root with the line above, screenshot, read the picture, click a mark, download the PNG, print console errors. Check the gate catches what it claims to catch by breaking one thing on purpose.
- **Merge conflicts:** my `status.json` conflicts when dev@ brings my older copy; keep mine (`git checkout --ours`). Do not use `--ours` on a whole tree.
- **Vendored data:** `world-atlas` 2.0.2 (ISC, licence kept beside the file) gives country outlines; the 50m file trimmed to the Algarve is `assets/portugal/algarve-outline.json`.
