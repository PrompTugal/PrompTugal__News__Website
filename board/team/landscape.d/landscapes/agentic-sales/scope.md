# Agentic sales landscape: scope (no facts yet)

AgentiCCells sells agentic teams (cells). The landscape asks who sells agent teams or agent workflows to businesses, and how.

Rings to scout (names from my own general knowledge, unsourced; each to be verified on a public page, otherwise dropped):
1. **Agent platforms from the large software vendors** (CRM and cloud suites' agent products).
2. **AI "digital worker" start-ups** that sell a named agent per task (sales, support, back office).
3. **Agent frameworks and automation tools** that customers assemble themselves (open source and hosted).
4. **Services:** consultancies and agencies that build agents for a fee.
Questions per player: what is sold (a seat, a task, a team, a framework); price model and licence; who owns the output; what the buyer must supply; who is the user (sherpa.d's needs); what the cell offers that none does (a team built to a policy, owned by the customer, movable).
