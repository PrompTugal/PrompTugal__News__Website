- release.sh's plain rebase flattens merges (it hit a conflict replaying 315 commits): fixed by merging dev when the range has merges.
- Prose in a feature's strings counts against the quality ratchet: words go in assets/*.json, not the .mjs.
- The live api/v1 can lag a deploy for a few minutes (cache): check with a query string before saying it is live.
- Names in git output: read with -z and as bytes (latin1), never line by line or decoded.
