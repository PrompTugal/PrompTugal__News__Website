## What I learnt

- A cherry-picked commit gets a new hash, so the worker's branch still shows it as "ahead". Review with `git cherry -v` or a path-limited diff, never by counting commits.
- The gate wants every page linked, in the sitemap and in `llms.txt`. A page that must stay unlinked until a review ships switched off (`ENABLED = false`), not as an orphan.
- Strings in build code count against the quality line. Put the words in `assets/<feature>/*.json`, never in `data/` (each new data file needs a schema, which is ontologist@'s).
- Playwright's `text=` selector matches case-insensitively and finds the paragraph before the button. Use `button:has-text(...)`.
- Hourly live-data refreshes conflict with each other. Take the newer `read_at`.
