# 07 Glossary

| Holacracy | Our word, and where |
|---|---|
| Role | A role file or brief, plus the agent's policy grant |
| Purpose | The first line of the role file |
| Domain | The paths and tools an agent's grant lets it change |
| Accountability | The "owns" lines |
| Circle | A project and its sub-circles |
| Anchor circle | Dinis's whole estate |
| Circle Lead | A conductor; Dinis for sgit.ai |
| Circle Rep | Missing; holacracy.d where there is none |
| Facilitator | Policy and review agents, lightly |
| Secretary | holacracy.d for the governance record; status files and debriefs for the rest |
| Tension | An ask, a finding, a report of being blocked |
| Proposal | A file in `proposals/` |
| Governance meeting | A proposal and Dinis's answer in a session |
| Tactical meeting | An agent's wake |
| Objection | An outstanding line in a proposal from a lead or a reviewing agent |
| Constitution | The rules of each repository and the policies |
| Governance record | `org-chart.json` and the decisions |
| Filler | The agent (or person) in a role |
| Twin | The same role, filled on a second account |
