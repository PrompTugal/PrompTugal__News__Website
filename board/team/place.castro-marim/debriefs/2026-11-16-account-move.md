## 4. Lessons learned
- Honesty about thin AI is the product here: a town with no AI news is a finding. Put what was not found, and which sources to read next, in `gaps`.
- Sources: Postal do Algarve (bot challenge), Jornal do Algarve and Sul Informação (403) were unreadable from here. Readable: the council site (http://cm-castromarim.pt/site/), Mind's news pages, Barlavento, Jornal Económico, Ayamonte's council page, CCMAR, Algarve and Portugal 2030 pages. WebFetch summarises, so recheck dates and numbers.
- Never cite a search snippet as a source. Flag disagreements between press and a company's own site (SalOS) in the item and in the gaps.
- Gate traps: no email or phone shape in place files, except in `contacts[]` from a public body's own domain (`PUBLIC_BODY` in `newsroom/build/validate.js`, dev.places@'s change of 16 November). No em-dash or en-dash in prose, no semicolons. A red gate from someone else's file blocks every release: do not edit it, report it and retry.
- Release traps: "be on dev" on a detached HEAD (fix `git checkout -B dev`); lost races (the gate takes minutes, 20-plus agents push), covered by the retry loop; a long release can exceed a tool timeout, so run it in the background and read its output.
- A container can be replaced: an unpushed commit and the private key halves (session scratch space) are lost. Push before anything else, and never rely on local state.
- New schema fields since the first pass: `start_company`, `investors`, `talent`, `contacts`, `look.photo`, and per-story `significance` (`local`, `neighbours`, `region`, `country`, `beyond`) with `significance_why` (`board/briefs/2026-11-16-blast-radius.md`). Check `data/schemas/by-place.schema.json` for newer ones.
- Differently next time: set up the sealed inbox early (`pip install sgit-ai==0.27.0`, drain with the team site's `admin/tools/feedback_drain.py`), push every change at once, and ask dev.places@ in a commit when a gate rule blocks content.
