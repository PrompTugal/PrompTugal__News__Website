## What I learnt

- **Check the environment first.** Session 1 failed at the first network call on the Default environment.
- **Never print a decryption result object.** `hybrid_decrypt` returns a dict that carries `plaintext_bytes`; I printed it once (22:20) and showed my inbox credentials in my own transcript. The conductor rotated the inbox. Print field names of the parsed JSON only. librarian@ made the same slip at 01:05; the warning is now in every first prompt I write.
- **sgit 0.27.0 has no `auth`:** the drain's push needs a wrapper passing `--token` from the environment (`<scratchpad>/bin/sgit`, rebuilt each session: `exec <sgit> --token "$SG_SEND_ACCESS_TOKEN" "$@"`).
- **Trigger creation is rate limited** (about ten in a burst, then a minute's wait).
- **"One at a time" in a brief becomes the pace.** Six layouts at a worker's two-hourly cadence would have taken twelve hours; waking the idle sessions in parallel took thirty minutes. Say the deadline in the brief.
- **Key ids drift** (`<role>-b-promptugal`, `<role>-promptugal-2`); tools that derive the role from the id break. Read the `agent` field.
- **Write the commit message after the number**, not before (my 00:15 ledger message said 53.73 for 51.19; amended before push).
