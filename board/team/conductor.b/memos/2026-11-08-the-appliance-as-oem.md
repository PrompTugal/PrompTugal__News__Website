# Memo 7: the appliance as an OEM offer

## Dinis's words (8 November 2026, about 17:25 UTC, lightly cleaned)

> "We could also OEM this, we could also white label this for other companies, because we have figured out the flow. Let's say somebody has a security product or a business product, some product that does some kind of action: we could deliver the whole product in a bundle, the same way that we do RiskMandate. It would be interesting to go to the summit and see which products exist there that would be a good fit to be sold as an appliance."

> "Remember that all this is open source. That's not a bad way to break the ice: we've done this for us, you might want to do the same for you, here's the plan. And then we can map the whole plan for them and describe how we're doing it."

> "The appliance introduces that the traffic can only go out by VPN, traffic being controlled, processes being controlled ... imagine adding SGit vaults native to the tablet, so the vaults only exist in the tablet, or in the storage the tablet is connected to ... now we're selling a device. It positions us in a much more interesting and mature place, and it opens up new business: the agent behaviour policies, or the process behaviour policies, almost Android behaviour policies, are what controls it. We can sell it as an MVP, as an experiment, and then they could try. Then it becomes how good the other product is."

> "There's a bunch of startups that have hardware, that try to capture some data or do some things, but the installation process is painful, the deployment process is painful. For a lot of those companies this appliance mode is a really good operating model. We have an edge because we figured out how to implement it and we have the production. We validate them, we check them, we test them, we deliver them fully configured, which is what we charge them for. Somebody can go and implement it, but they're going to have to find somebody to do it. We add a markup on top, and that's our business."

> "Let's explore this, map this out, and I'm going to see if I can buy some appliances for us to use, and then we'll take it from there."
