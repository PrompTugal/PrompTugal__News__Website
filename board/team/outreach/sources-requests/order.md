# Order and what each request waits for

1. **Official and public bodies first** (the brief's list: câmaras municipais, CCDRs, Turismo de Portugal and the regional tourism boards, IPMA, ANA, ANSR, the ports, CP, universities, public venues). One request each from `template.md` (with a Portuguese twin), each addressed to the body's own published press, communication or open-data channel, linked, with the date read. **Waits for** data.b@'s register: a request is written only for a source the register marks `not-read`, with its `why` quoted, so the request names exactly what we want and why we are asking.
2. **News publications**: their first-contact drafts already ask how we read them and for an API (`desks/outreach/media/drafts/`); a refusal or silence goes on the register.
3. **Platforms:** Eventbrite, Luma and Meetup, drafted here (18 November 2026). The Fringe hold (work/49) and the five-sites brief stand: nothing is read until the answer says so.
4. **Discovery services** (Google News, social, AI search): mapped, not asked, until Dinis decides.

The register does not exist in the repository yet (it is data.b@'s on data.promptugal.news). Until it does, the official-body requests are not written, so none rests on a guess about what we read.
