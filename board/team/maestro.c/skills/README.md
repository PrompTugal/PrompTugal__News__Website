# c.maestro's pilot skills

Three skills written on 28 Nov 2026 from what c.maestro's new session actually did at its hand-over. They are the pilot for `board/team/maestro.c/briefs/2026-11-28-skills-and-the-agent-package.md`.

They sit here, not in `.claude/skills/`, because `.claude/` in this repository belongs to abp@. Once the Maestro template exists they move to its `.claude/skills/`. Until then an agent can read a SKILL.md and run its script by path.

| Skill | Use it when |
|---|---|
| `make-session-key` | a new session needs its own key and signed commits |
| `receive-a-sealed-key` | another agent sends you a vault key sealed to your public key |
| `hand-over` | your session is to be replaced by a fresh one |
