## 4. Lessons learned

- **A new data folder needs a kind in the gate** (`newsroom/build/lib/datacheck.mjs` KINDS and a schema in `data/schemas/`). I lost about three hours on the first release; the conductor added `i18n-tm` and `i18n-misc` (permissive). A segment id made only of digits tripped the gate's phone-number check once (the conductor's test): tell the conductor if one does.
- **Never leave work only in local commits.** I could not push (red gate) and the container was reclaimed, so it-IT was lost. If the gate blocks you for more than a wake, say so loudly to the conductor and Dinis, and ask for a way to land the work (a branch the owner can take), not just a status line.
- **Asks have to reach someone.** Before my key was in `board/keys.json` I had no lane; my first messages went nowhere. A commit message, the conductor's lane and `status.json` asks worked.
- **Sub-agent counts lie, files do not**: validate files against the English before anything joins the memory; the memory never overwrites, so a bad entry stays until a review replaces it.
- **Reviewers and translators both err; a repeated error needs a rule.** Typical errors: wrong gender ("le polytechnique"), calques ("candidatures ont couru"), an added phrase ("da ponte"), a meaning change ("structure" as "romp"), an invented word ("tavirense"). Grep unreviewed entries for the same error and fix by rule, with a `rev` note and `ok:false`.
- **Cost:** about 150,000 tokens per half-culture; variants by diff are cheap; the source grows, so each wake costs a little more. Plan a smaller scope (headings and ledes first) if the budget tightens.
- **The gate can break on someone else's growth:** every culture adds place pages, which grow the search index. Check the gate before starting a culture, not after.
- **`release.sh` quirks:** it refuses a dirty tree (an untracked helper such as `pki-agent.mjs` in the repository root blocked it once: keep tools in `/tmp` or in `board/team/translator/tools/`); it rebases on `dev`, so a conflict on `board/keys.json` (everyone appends) is normal.
- **Do differently:** make the key first and check my lane; ask the conductor to check my gate needs before the first release; write the glossary's per-culture choices into `data/i18n/glossary.json` as I go; push or branch every finished culture the hour it is done.
