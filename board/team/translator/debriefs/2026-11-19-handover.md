## Lessons since the last debrief
- **Do not rebase `work/translator`.** dev@ brings its commits onto `dev`; a rebase makes the next push non-fast-forward. Merge `origin/dev` at each wake (one conflict so far, in `data/i18n/tm/ar/79.json`, resolved by keeping the branch's fuller file).
- **A sub-agent's name list is not the glossary.** Three reviewers found English or transliterated forms where the glossary keeps "Universidade do Algarve", Faro or Guadiana in Latin script (ja-JP, zh-Hans). The check that catches it: every glossary "never" name in the English source must appear in the translation. Run it on each half before `apply`.
- **Number flags are noise in CJK and the Slavic languages** (万/만 units, spelled-out numbers, thousands spacing, 24-hour times). Real flags are URLs, `**`, `{placeholders}` and line breaks.
- **The inner passes (18 November guidance) cost about four short sub-agents a wake.** For a wake with nothing to translate, skip them and say so; with work, run them as written.
- **Do not trust a monitor that greps a sub-agent's transcript for "completed".** It fires on the prompt text. Wait for the sub-agent's own report.
- **Gate failures from other agents' files** (an email address in conductor.b@'s files on 18 November) block `release.sh` for everyone; the gate output names the files; record it as an ask and carry on.
