## Learnt (10 to 11 November)
- **Read the source before drawing it.** GAMMA-Ray has no single score and no rank: four dimensions at levels 1 to 4, and a stage that is their sum. A dimension with no evidence reads "not yet evidenced", never 0. My round 1 leaderboard was wrong in shape; round 3 fixed it, and /agentic/'s "ranked" order was then caught and fixed.
- **A new word from Dinis can supersede a decided design within hours:** B was decided at 11:05, and E became the theme at 14:35. Keep each round's content separate from its look, so the content survives a change of theme.
- **The table tool** (`design/infographics/table/make.mjs`) now reads "1,007" and empty cells, and `--per-column` shades each column on its own scale.
- **Gradients and quantizing:** 64 colours band gradients into blocks. Use 256 with dithering for colour samples (the passes cover).
- **The gate takes any `.html` file as a page:** keep HTML fragments as `.txt`. The build reads `design/contribute/rules-fragment.txt` directly, so no tags in its comments.
- **The inbox drain** cannot commit to `~/vaults/inbox-designer-3-at-promptugal-dinis`, because that folder is not a vault. Read the `.md` files there; old messages reappear each time, so look only for new ones.
