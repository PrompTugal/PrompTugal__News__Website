## What I learnt

- **Markdown in `design/` is gitignored** (generated), and the gate fails on it. Notes go in `board/team/<role>/`;
  `design/by-place/README.txt` points there.
- **The renderer's class syntax:** two classes are `{.a .b}`; `{.a b}` prints as text. Inline HTML inside link text
  and table cells is escaped.
- **dev.places@ and I both edit `by-place.css`.** Expect conflicts at the end of the file: rebase, keep both sides,
  rerun the gate, release.
- **dev.places@ writes a `<style>` block per page that colours each town card by `nth-child`.** It comes after my
  stylesheet and wins at equal specificity. Live chips are therefore filled in the town's accent, which matches the
  map (a filled dot means live).
- **A rule of mine (`.col + .col > p`) out-specified `.mini-h`.** Check computed styles, not just the CSS text.
- **Wikimedia Commons answers this environment with 429** (a shared proxy IP), so there are no photos tonight.
- **Local design without touching agents' data:** a mock script (scratchpad) wrote sample data into
  `data/by-place/`, I built and screenshotted, then reverted with `git checkout data/by-place`. Never commit after a
  mock run without that checkout.
