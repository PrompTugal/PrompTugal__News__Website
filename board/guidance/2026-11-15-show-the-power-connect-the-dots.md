# Show the power: connect the dots

Maybe we use Loulé and Faro as the case study, double down on that, and once those are good, expand to the others."

It's that whole flow of mappings that becomes very interesting: the intersection between everything, because everything should now have connections. Who can talk to, who should be talking to, who's connected to what, the whole semantic graphs. That's why the ontologists are super critical, and the mappings of the data and the visualization."

> "You have an OpenRouter key here. Maybe not get all of them, but have a mode of connecting the dots, and start using OpenRouter to make this website look as professional as possible."

> "I don't know if we already have a social media one, but it'd be good to include social media. We need some detectives to go and find everything AI related that is happening around here, and then connect the dots. This now allows us to go to every single one of those companies. That's the punchline I need: to be able to show the power of this."

> "How can we make this all data-driven? Every one of these should have a database online. We should have the graph, the SQL query; we should be able to run queries across everything. Put this into visualizations, ways to present it, custom decks. Remember all the visualizations we've done for the other websites."

> "I really want them to run on a loop. We have 24 hours. Look at the way I've done the book, all of those materials and capabilities: this is really what we need to be doing now, so that we have a website that is as spectacular as possible. Running stories, very news-like, connecting the dots. The pages should look very professional, like a website with side things."

> "The PrompTugal iOS app also needs to be very visual. There were some very interesting news iPad apps in the early days of mobile, very visual, with lots of visual elements. We should bring some of those things back."

Use the characters from the book I created, the mini infographics, even the happy faces, to show who is working on what, all powered by reality."

> "For every news story, on the side: the provenance, when it was done, what was collected, screenshots. You can create vaults to store screenshots of third-party websites we grab. The provenance line has to be super powerful. And have some good case studies for me to show."

> "We also have the newsroom section, the back office, all online. Each one of these needs a newsroom. How can we visualize the newsroom actually working in practice? We have real examples and real data. Let's see that visualization end to end."
