# How we work

- **PKI on everything:** "every device, every installation, every application needs to have its own key", even every version; map them, the handshakes and the authorisation levels; swap public keys in person by QR code and NFC (in the internal apps); signing is a graph; "a full-blown PKI infrastructure, all the way from web browsers to users' keys, to keys that only exist in a device, to user passkeys", visualised. Something we can sell.
- **The live picture:** the communications drawn, agents coming online and going offline, "look at me sending a message, look how it flies", tablet-to-agent through vaults; vaults run it all "with only encrypted infrastructure and storage infrastructure".
- **Agents' life cycle:** a scheduled agent that has done nothing for a while is stopped; one silent for about a day is archived; everything is on GitHub, so any can be restarted.
- **First, how the team collaborates:** daily debriefs, an intranet of simple pages (what are we selling, what is RiskMandate, what is going on, which companies we talk to), questions at log-in; "everything should be public" unless it crosses the confidential line (find each person's line; even location could be a public demo, with permission); a local model and the scheduled strong models working together, mapped with their ABPs.
- "This collaboration, these flows, how we communicate, how we know what we're doing, how we map out, is the key of what we are trying to do here."
