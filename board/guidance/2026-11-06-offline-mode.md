# An offline mode

- "I was talking to Silvio, and Silvio was putting the idea of having an offline mode for our PT.news, and I think it's a really cool idea. And actually, that's a good example of capturing the articles that the user wants, which you basically can store that on local storage."

- "So we should definitely have an offline mode so that, for example, you always have the schedule, you always have this, you always have some articles, even articles to read, we can actually cache it ... So we just make sure that the website has an offline mode, which is actually very important. You can add that to the list of stuff to build."
